# Post-M409.1 — Curiosity Knowledge Candidate Admission Classification Foundation v1

## Status

IMPLEMENTED / CERTIFICATION PENDING USER GATES.

## Purpose

Classify the intended governed admission destination of a certified curiosity
knowledge candidate without performing admission.

Outcomes are `KNOWLEDGE`, `MEMORY`, `KNOWLEDGE_AND_MEMORY`,
`REVIEW_REQUIRED`, and `REJECT`.

The classification preserves candidate, question, human-answer, speaker and
epistemic provenance.

## Governance

This v1 is read-only. It does not persist, write memory, write knowledge,
create or invoke learning, wire the conversation Gateway, execute actions or
create a new authority.

Correction, conflict and non-fact candidates require review. Personal or
sensitive evidence is not routed to general knowledge. Learning ownership
remains explicitly deferred to the separate writer-vs-evaluator gate.

M410, networking and Residential remain out of scope.
