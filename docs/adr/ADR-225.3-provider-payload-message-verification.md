# ADR 225.3 — Provider Payload Message Verification

## Status
Accepted.

## Context
M225.2 exposed structured-message summaries, but the legacy prompt block followed the
message block. Operators copying the tail of `--observe` could therefore miss the decisive
evidence and mistake the compatibility prompt for the actual provider transport.

## Decision
The development observer now reports the governed provider endpoint path and exact role
sequence. In explicit `--observe` mode, the provider-message block is rendered last and is
terminated by `provider_transport_verified`. Ordinary `/last` and `/trace` views remain
content-redacted.

## Consequences
This milestone changes observability only. It does not alter message construction,
curation, routing, provider invocation, persistence, or model behavior.
