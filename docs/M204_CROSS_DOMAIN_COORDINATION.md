# M204 — Cross-Domain Coordination

M204 converts shared cognitive infrastructure into consultative cross-domain coordination.

## Capabilities

- Correlates M201 blackboard state, M202 global state, and M203 events.
- Preserves owner/session isolation.
- Detects conflicting values published under the same event topic.
- Prioritizes constraint resolution, conflict reconciliation, signal-quality recovery, or blocking-boundary preservation.
- Produces deterministic, immutable directives with exact lineage.
- Publishes the latest coordination status as a governed blackboard candidate.
- Contains no execution, provider, memory, planning, tool, or final arbitration authority.

## Runtime order

`M201 → M202 → M203 → M204`
