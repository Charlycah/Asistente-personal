# RF-E GAP A — Bounded Grammar Compatibility — Implementation v1

## Status

Implementation candidate. Final closure requires `ruff check .` and full `pytest -q`.

## Purpose

Extend the existing governed contextual-rule interpretation authority with one closed
compatibility form used by the historical Neral AAT. No general parser is added.

The existing IF/AND/THEN grammar remains unchanged. The additional bounded form is:

`si C1, y C2, RESULT mientras no exista una alternativa.`

It is represented as the same three conditions plus one conclusion already consumed by
the certified exclusive-dependency capability-loss semantic family.

## Provenance

When a trailing conversational comment follows the bounded rule sentence, only the
exact rule sentence is exposed as `rule_source_text`; the complete turn remains
`source_text`. Offsets continue to match the original text exactly.

## Semantic compatibility

The bounded semantic grounder accepts `no exista una alternativa` as an additional
surface form for the already existing `ALTERNATIVE=absent` slot. No predicate, role,
relation, claim type, or semantic family is added.

## Governance

This increment does not make `entonces` optional in the general grammar and does not
make `mientras` a general logical operator. Unsupported operators and vague rule forms
continue to fail closed.

No provider, retrieval, persistence, Memory/Learning, new registry, new authority,
action execution, or downstream admission/inference contract is added or changed.
