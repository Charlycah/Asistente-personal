# M388.6 — Diagnóstico integral de cierre de brechas

## Objetivo

Medir el resultado de M388.2–M388.5 sin conectar capacidades nuevas ni cambiar
el comportamiento productivo.

## Dos dimensiones distintas

El diagnóstico separa:

1. cierre estructural: existe un adaptador canónico conectado para la brecha;
2. demostración operacional: el nodo participó realmente en un turno retenido.

La existencia de código no se confunde con actividad real. Un nodo observado
como omitido, degradado o bloqueado conserva esa evidencia, pero no se declara
operacionalmente demostrado.

## Resultado estructural

Las cuatro brechas originales posteriores a M387 poseen cierre estructural:

- `perception_and_evidence` — M388.2;
- `epistemic_classification` — M388.3;
- `cognitive_state` — M388.4;
- `relational_affective_context` — M388.5.

## Límites

El diagnóstico es inmutable, de solo lectura y no contiene conversación,
identidades, recuerdos o respuestas. No ejecuta runtime, memoria, proveedores,
decisiones o acciones externas. Tampoco concede autoridad.

El cierre estructural no significa que todos los escenarios hayan participado.
La demostración operacional depende de canales, claims, autoridades y contexto
reales disponibles durante los turnos observados.
