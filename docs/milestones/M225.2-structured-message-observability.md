# M225.2 — Structured Message Transport Observability

## Objetivo

Verificar en runtime si cada solicitud usa mensajes estructurados o el fallback de prompt plano.

## Criterios de aceptación

- Conteos por rol visibles en el resumen.
- Transporte `messages` o `prompt` visible.
- Mensajes completos visibles únicamente en `--observe`.
- Compatibilidad con observaciones históricas sin resultado vivo.
