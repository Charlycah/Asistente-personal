# M251 — Knowledge Runtime

M251 connects ROBY's existing knowledge-source assessment path to the official
runtime and capability registry.

The official gateway classifies each request for internal confidence, current
information, explicit external lookup, verification, and local-document use.
The same gateway is used by runtime preparation and by the operational
capability exposed through conversation and the desktop capability panel.

M251 does not silently enable network execution. Source assessment and
retrieval planning remain distinct from authorization and execution.
