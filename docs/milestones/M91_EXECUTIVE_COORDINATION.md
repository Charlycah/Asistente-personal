# M91 — Executive Coordination

M91 coordina planes ejecutivos M90 mediante directivas gobernadas dirigidas a
subsistemas cognitivos y operativos. No ejecuta las directivas.

## Capacidades

- Directivas por subsistema, hito, prioridad y secuencia.
- Dependencias y restricciones explícitas.
- Coordinaciones inmutables con historial de revisiones.
- Estados gobernados para coordinación y directivas.
- Revisión obligatoria para autonomía, revisión humana o prioridad crítica.
- Integración opcional con `CognitivePipeline`.

## Límites

M91 no crea tareas, no calendariza, no invoca herramientas, no concede permisos,
no altera conocimiento y no sustituye M69/M70.
