# M208 — Cognitive Health Monitoring

M208 adds whole-system cognitive health observation over the fused context produced by M207.

## Capabilities

- Deterministic and immutable health reports.
- Health states: `healthy`, `watch`, `degraded`, `critical`.
- Dimensions for context coverage, signal confidence, coherence, and availability.
- Explicit alerts for conflicts, constraints, and deferred actions.
- Owner/session isolation and complete source lineage.
- Governed health publication to the Unified Cognitive Blackboard.
- Official runtime placement immediately after M207.

## Non-authority

M208 is observational. It does not repair, schedule, arbitrate, execute, mutate memory, choose providers, or bypass existing governance.
