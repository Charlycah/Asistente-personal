# M205 — Unified Cognitive Scheduler

M205 turns M204 cross-domain coordination directives into deterministic, governed cognitive schedules.

## Capabilities

- immutable schedule and schedule-item models;
- ordered priorities with explicit dependencies;
- idle, scheduled, attention-required, and blocked states;
- owner/session isolation and exact source lineage;
- governed schedule-status publication to M201;
- official runtime integration immediately after M204.

## Boundary

M205 is advisory. It does not execute work, invoke tools, change memory, alter plans, select providers, or perform executive arbitration.
