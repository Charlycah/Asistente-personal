# M76 — Daily Briefing

M76 agrega una capa de síntesis diaria sobre Household Memory, Document Inbox,
Personal Knowledge Base y Task Intelligence.

## Alcance

- Resúmenes de mañana, tarde o bajo demanda.
- Priorización de vencimientos, tareas y revisiones pendientes.
- Filtrado por propietario de tareas.
- Severidades informativa, atención y urgente.
- Salida determinista en texto y diccionario.
- Integración con Scope Guard y Cognitive Pipeline.

## Fuera de alcance

- Envío automático por correo o mensajería.
- Ejecución de tareas.
- Operaciones bancarias, pagos, billeteras o compras.
- Recomendaciones médicas o legales autónomas.
