# M202 — Global Cognitive State

M202 projects the governed M201 blackboard into one explicit, traceable representation of ROBY's current cognitive condition.

## Capabilities

- Stable, limited, blocked, and degraded readiness states.
- Aggregation of active cognitive domains.
- Signal count and average-confidence projection.
- Explicit constraint preservation.
- Conversation-readiness, cross-domain-visibility, and signal-quality dimensions.
- Deterministic state identity and source lineage.
- Publication of the state back to M201 as governed system context.
- Protection against recursive self-aggregation.
- Official runtime contribution immediately after M201.

## Governance

The global cognitive state is advisory. It does not execute actions, grant permissions, select providers, alter plans, modify memory, arbitrate priorities, or bypass operational controls.

## Runtime order

`M196 → M197 → M198 → M199 → M200 → M201 → M202 → existing cognitive contributors`

## Validation

M202 adds focused tests for stable, limited, blocked, and degraded states; domain and confidence aggregation; constraint preservation; blackboard publication; runtime ordering; request preservation; and dependency enforcement.
