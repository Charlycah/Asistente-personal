# Self-Diagnostic Opportunity → Diagnostic Proposal → Governed Proposal Reachability

## Decision

The certified 12,361 baseline already contained every authority required after a
reproduced diagnostic proof, but no bounded composition joined the complete explicit
M399 evidence chain to the already-certified governed-proposal presentation path.

The permitted closure is deliberately **explicit and non-resident**. M399.2-M399.4
permanently forbid background monitoring, causal invention and automatic hypothesis
generation. Therefore this surgery does not manufacture an "opportunity" from runtime
signals and does not add a self-monitoring resident.

## Canonical chain

`SelfDiagnosticOpportunity` (explicit observations + threshold + explicit hypothesis +
hash-bound project evidence) → existing `GovernedSelfDiagnostics.diagnose()` → existing
hypothesis assessment → existing reproducible proof → existing
`generate_diagnostic_proposal_request()` → existing M399.5 isolated
`DiagnosticProposal` → existing `SelfImprovementGovernedProposalReachability` → existing
`GovernedProposalModel` / `GovernedProposalInbox`.

The already-certified Governed Proposal → Executive Notification runtime remains the
only downstream unsolicited presentation path.

## Authority boundaries

`SelfDiagnosticOpportunityGovernedProposalReachability` is composition only. It receives
the existing `GovernedSelfDiagnostics` authority and the existing self-improvement
proposal reachability adapter. It owns no diagnostic authority, hypothesis generator,
proposal model, proposal inbox, notification broker, persistence, background monitor,
approval authority, code writer or execution permission.

Permanent boundary:

`explicit evidence → reproduce → propose → notify → human review`

never:

`observe → infer cause → self-authorize → mutate code`.

## Productive boundary

This closure makes the complete explicit opportunity-to-governed-proposal chain callable
as one application service. It does **not** claim autonomous runtime opportunity
discovery. A future runtime source may submit an opportunity only if it already owns the
technical observations and can supply the explicit M399 hypothesis/evidence contract
without violating source authority.
