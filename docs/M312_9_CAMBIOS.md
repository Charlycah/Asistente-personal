# M312.9 — Resolución de identidad activa

- Agrega resolución explícita y no biométrica de Carlos, Cristina, Familia o desconocido.
- Acepta perfil explícito, perfil de sesión o nombre declarado.
- Los conflictos nunca se adivinan y quedan bloqueados.
- Un perfil compartido no habilita preferencias privadas.
- La composición del BRAIN expone el resolver sin conectarlo al runtime visible.
