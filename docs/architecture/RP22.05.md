# RP.22.05 — Observabilidad y exportación controlada

## Objetivo

Exponer, únicamente bajo solicitud explícita, snapshots versionados del estado observable del Cognitive Decision Kernel sin incorporar telemetría, persistencia ni autoridad de ejecución.

## Decisiones de diseño

- El exportador es puro: recibe métricas, calibración y explicación y devuelve un contrato inmutable.
- El perfil `summary` omite la explicación completa.
- El perfil `diagnostic` incluye la explicación estructurada, pero redacta la narrativa libre.
- No se escriben archivos, no se transmiten datos y no se altera ninguna política.
- El runtime conserva compatibilidad fail-open con kernels anteriores.

## Componentes modificados

- `core/cognitive_planning/observability.py`
- `core/cognitive_planning/decision_kernel.py`
- `core/cognitive_planning/__init__.py`
- `app/cognitive_planner_shadow_runtime.py`
- `tests/test_rp_22_05_kernel_observability.py`

## Flujo

```text
metrics + calibration + explanation
                 |
                 v
      explicit export request
                 |
                 v
 profile filtering + redaction
                 |
                 v
 immutable transport snapshot
```

## Impacto

La revisión habilita diagnóstico estructurado y seguro, pero no crea endpoints, archivos, telemetría externa ni realimentación hacia el kernel.

## Pruebas añadidas

Cinco pruebas cubren perfiles, redacción, exportación sin decisión, determinismo y compatibilidad fail-open.
