# M358 — Document Intelligence gobernado

M358 integra clasificación y extracción para producir una comprensión explicable
del documento: resumen, completitud, consistencia, campos faltantes y observaciones.

La operación requiere permiso de cámara, consentimiento explícito y solicitud
directa. Usa una sola captura y no conserva la imagen.

## Límites

M358 no consulta la web, no valida fiscalmente, no paga, no modifica documentos,
no crea recordatorios y no toma decisiones automáticas. Las inconsistencias son
advertencias deterministas basadas en evidencia OCR, no conclusiones legales.
