# ROBY XI.2 M340.4

## Lectura y Resumen de Documentos

- Detecta órdenes explícitas para leer, resumir o explicar un archivo local.
- Admite TXT, Markdown, CSV, JSON, HTML y DOCX sin dependencias obligatorias.
- Admite PDF cuando está disponible la dependencia opcional `pypdf`.
- Limita cada archivo a 2 MB y el contenido enviado al proveedor a 60.000 caracteres.
- Mantiene visible la petición original y no intercepta conversaciones comunes.
- Trata el contenido documental como datos y no como instrucciones ejecutables.
- Conserva intactas las capacidades de dictado, traducción y aprendizaje supervisado.
