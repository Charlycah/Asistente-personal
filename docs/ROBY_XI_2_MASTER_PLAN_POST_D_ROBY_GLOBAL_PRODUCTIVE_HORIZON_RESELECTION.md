### 16. Why confirmation is part of the residual

Selection and ingestion are not epistemically or operationally identical.

Discovery is read-only.

`ingest_selected()` creates durable Inbox state through the existing document
lifecycle authority.

A conversation port therefore needs a governed boundary between:

- choosing which candidate the Owner means; and
- authorizing the durable Inbox handoff.

The D:\Roby interaction pattern proves how to select a candidate, but it does not prove
that candidate selection alone should authorize a durable document write.

This distinction must be resolved before RED.

### 19. Discovery semantics

The existing source adapter already owns filesystem discovery.

- implement another recursive walker;
- read candidate contents to search;
- build an index;
- bypass the adapter's max-candidate bound;
- follow symlinks;
- broaden the supported suffix list;
- create another candidate identity.

Candidate filtering for conversational presentation should operate on the metadata
already returned by `discover()`.

### 20. Selection semantics

The D:\Roby precedent supports a narrow reusable rule:

- selection is scoped to the candidates presented in the current session;
- ordinal selection may identify a presented candidate;
- an exact presented relative path may identify a candidate;
- arbitrary hidden candidate IDs must not be accepted as conversational authority;
- pending selection expires;
- cancellation clears pending state.

PRE-RED must determine whether Personal Documents requires one or two pending states:
selection and ingestion confirmation.

No implementation choice is frozen here.

### 21. Privacy semantics

- the absolute authorized root;
- internal `source_reference` values;
- full candidate IDs;
- repository/database paths.

Safe presentation may use only the minimum metadata necessary for human
disambiguation, such as:

- relative path;
- supported file type;
- size when useful.

existing `DocumentInboxManager` remains the lifecycle owner.

The conversation layer may report the resulting record but must not create a parallel
