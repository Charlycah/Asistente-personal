# Post-M409.1 — Productive Conversational Curiosity Wiring v1

## Status

IMPLEMENTED / CERTIFICATION PENDING USER GATES.

## Purpose

Productively realize a certified governed epistemic curiosity question only
after the existing relevance and personal initiative services admit it.

The productive path is:

structured multisource epistemic gap -> Curiosity v1 question candidate ->
existing RelevanceEvaluator -> existing PersonalInitiativeEngine -> minimal
productive curiosity wiring -> OfficialConversationGateway interceptor response.

## Governance

The Gateway remains the single conversational boundary. Curiosity gains no new
authority. The wiring does not create governed proposals or proposal inbox
entries and does not persist questions, write memory, create learning
candidates, modify knowledge, call a provider, retrieve data, access the
network, execute actions or start background work.

When existing initiative policy returns DEFER or DISCARD, no curiosity
interceptor response is produced and the prior conversational route remains
available. External evidence retains its existing precedence.

M410, networking and Residential remain out of scope.
