# M348.9 — Vision Core

## Objetivo

Establecer la infraestructura oficial y gobernada para que ROBY pueda solicitar una captura puntual de una cámara USB local sin incorporar todavía análisis visual.

## Flujo

`VisionCaptureRequest → OfficialVisionCore → CameraProvider → IntelligentVisionService → VisionCaptureResult`

## Garantías

- no se accede a la cámara sin permiso, consentimiento y solicitud explícita;
- cada solicitud produce como máximo una captura;
- los bytes de la imagen no forman parte del resultado público ni del snapshot;
- la observación pasa por la política visual canónica existente;
- no hay ejecución continua, persistencia de imágenes, biometría ni servicios externos.

## Alcance posterior

Sobre esta base podrán incorporarse, en milestones separados, detección de presencia, OCR, códigos QR, objetos y descripción de escenas. Cada capacidad deberá tener su propia política, adaptador y pruebas sin reemplazar este núcleo.

## Validación agregada

M348.9 añade 9 pruebas específicas. Junto con las pruebas relacionadas de cámara y visión, el corte local ejecutó 31 pruebas correctamente.
