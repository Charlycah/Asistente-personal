# Post-M409.1 — Hypothesis Deepening Epistemic Gap → Governed Curiosity Evidence Adapter Foundation v1

## Status

IMPLEMENTED. Official Ruff and full-suite certification remain user gates.

## Purpose

Provide the minimum read-only contract bridge required for an explicit
`HypothesisEpistemicGap` produced by `governed_reasoning` to become valid
`MultisourceKnowledgeGapEvidence` for the existing Governed Epistemic Curiosity
foundation.

## Ownership

- Source ownership remains `governed_reasoning`.
- Target question candidacy remains owned by Governed Epistemic Curiosity.
- The adapter is a pure projection and creates no new authority.
- M369 remains the learning authority.
- `OfficialMemoryGateway` remains the sole persistent personal-memory writer.

## Mapping

The adapter preserves the gap subject, known elements, unknown element and
hypothesis verbatim. Curiosity source kind is `REASONING`; the direct
`source_reference` is the exact `gap_id`. Upstream M391.3/M391.4 lineage remains
explicit in evidence codes through the hypothesis id, gap id and original
reasoning source reference.

Relevance is not inferred by the adapter. Its default is `UNKNOWN`, which makes
the existing Curiosity foundation fail closed with `ABSTAIN`. A higher governed
composition may provide an explicit relevance value later; the adapter itself
still does not create a question.

A hypothesis-deepening report with zero epistemic gaps projects zero Curiosity
evidence.

## Explicit non-capabilities

Foundation v1 does not create or emit questions, does not call conversation,
does not create learning candidates, does not write memory, does not modify the
world model, does not execute actions and does not grant authority.

M410, networking and Residential remain outside scope.
