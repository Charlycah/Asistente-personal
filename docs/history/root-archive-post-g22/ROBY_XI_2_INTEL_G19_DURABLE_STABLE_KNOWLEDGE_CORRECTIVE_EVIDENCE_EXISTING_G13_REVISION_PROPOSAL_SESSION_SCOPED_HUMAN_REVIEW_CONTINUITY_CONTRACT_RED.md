# ROBY XI.2 — INTEL-G19 — CONTRACT RED

## Gate

**EXISTING DURABLE STABLE KNOWLEDGE + GOVERNED CORRECTIVE EVIDENCE →
EXISTING G13 REVISION PROPOSAL → SESSION-SCOPED HUMAN REVIEW CONTINUITY**

## Purpose

Close only the revision-initiation and pending-human-review seam found by the
post-G18 architectural reconciliation.

G17/G18 already close certified revision execution. G19 must not touch Memory
persistence, G14 approval, G15 application, G16 certification, or G17 atomic
revision.

## Required seams

1. Reuse the existing `ProductiveGovernedLearningWiring`.
2. Reuse the existing `GovernedKnowledgeRevisionProposalFoundation` from G13.
3. Accept the exact durable `CognitiveMemoryRecord`, governed corrective
   `EvidenceReference` values, proposed replacement content, and session id.
4. Produce the exact inert G13 `GovernedKnowledgeRevisionProposal`.
5. Retain that exact proposal as bounded session-scoped pending human review.
6. Expose exact pending-proposal retrieval by session for a later explicit
   human response.

## STOP boundary

G19 proposal initiation must stop before:

- G14 `evaluate_revision(...)`;
- G15 application proposal;
- G16 request certification;
- G18 productive execution;
- any Memory write, supersession, archive, or mutation.

## Anti-duplication

Do not create a `KnowledgeRevisionManager`, `RevisionProposalInbox`, second
productive revision wiring, second G13 proposal authority, second approval
authority, or second Memory authority.

## Frozen distinctions

- CONTRADICTION != CORRECTION
- TARGET MATCH != TRUTH
- PROPOSED CONTENT != ACCEPTED CONTENT
- REVISION PROPOSAL != HUMAN APPROVAL
- PENDING REVIEW != APPROVED
- SESSION CONTINUITY != AUTHORIZATION
- PROPOSAL CREATION != MEMORY MUTATION
- ONE G13 PROPOSAL AUTHORITY
- ONE PRODUCTIVE APPROVAL-TO-MEMORY WIRING
- ONE MEMORY AUTHORITY
