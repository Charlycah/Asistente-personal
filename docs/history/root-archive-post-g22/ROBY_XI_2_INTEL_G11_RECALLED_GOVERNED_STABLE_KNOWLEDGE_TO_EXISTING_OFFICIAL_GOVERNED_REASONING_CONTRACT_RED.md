## Architectural residual

The official memory runtime already recalls durable knowledge and projects the selected
items into the operational request as bounded, read-only governed memory evidence.
The official cognitive runtime then invokes `ReasoningRuntimeContributor`, but the
contributor currently discards the enriched `LLMRequest` before invoking the existing
`CanonicalProductiveReasoningSource`. Consequently recalled `STABLE_KNOWLEDGE` reaches
the final provider prompt and Planning, but does not reach the existing official
governed reasoning authority.

## RED contract

G11 requires only the missing productive seam:

1. `ReasoningRuntimeContributor` must consume already-recalled governed memory evidence
   from the enriched request; it must not perform memory retrieval itself.
2. Only evidence whose category is `stable_knowledge` may cross this seam.
3. The exact bounded read-only evidence tuple must be forwarded through an explicit
   keyword-only `recalled_memory_evidence=()` seam.
4. `CanonicalProductiveReasoningSource` must expose that seam.
5. The same existing `OfficialGovernedReasoningRuntimeGateway` must expose the same seam.
6. No second Memory reader, Memory gateway, Reasoning gateway, authorization authority,
   external-evidence path, automation, or silent learning may be introduced.
