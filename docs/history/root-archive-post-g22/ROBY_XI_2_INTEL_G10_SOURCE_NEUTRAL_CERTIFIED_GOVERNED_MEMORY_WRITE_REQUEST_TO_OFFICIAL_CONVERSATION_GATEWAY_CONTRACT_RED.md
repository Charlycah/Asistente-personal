Therefore G10 freezes an additional semantic constraint:

- a source-neutral certified write request must not be conversationally represented as a preference;
- the official conversation response may remain concise and governed, but must preserve source-neutral meaning;
- historical preference wording must remain backward compatible for historical preference requests.

This is a presentation-layer distinction only. It does not create another memory category, authority, or route.
