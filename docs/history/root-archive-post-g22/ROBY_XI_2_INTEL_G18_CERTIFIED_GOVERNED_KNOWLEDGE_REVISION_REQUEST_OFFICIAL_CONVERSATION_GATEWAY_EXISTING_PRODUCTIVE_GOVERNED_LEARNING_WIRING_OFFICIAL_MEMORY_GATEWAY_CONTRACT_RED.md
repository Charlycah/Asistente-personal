# ROBY XI.2 — INTEL-G18 — CONTRACT RED

## Gate

**CERTIFIED GOVERNED KNOWLEDGE REVISION REQUEST → EXISTING OFFICIAL
CONVERSATION GATEWAY → EXISTING PRODUCTIVE GOVERNED LEARNING WIRING →
EXISTING OFFICIAL MEMORY GATEWAY**

## Purpose

Close only the productive reachability seam discovered after G17.

G13–G17 already provide the governed revision contracts and atomic durable
execution. G18 must not redesign those authorities. It only proves that an
already-certified G16 request can re-enter the ordinary official conversation
boundary and reach G17 through the same productive approval-to-Memory wiring
already used by governed learning.

## Required seams

1. `OfficialConversationGateway.submit(...)` accepts an exact
   `governed_knowledge_revision_request`.
2. The existing `ProductiveGovernedLearningWiring` exposes
   `execute_certified_revision_request(...)`.
3. That seam forwards the exact certified request to the already-injected
   `OfficialMemoryGateway.apply_governed_knowledge_revision(...)`.
4. The official conversation gateway routes through the existing productive
   wiring and does not call the Memory gateway directly.
5. No second revision wiring, Memory gateway, approval authority, request
   certification authority, or persistence authority is introduced.

## Frozen distinctions

- CAPABILITY EXISTS != PRODUCTIVELY REACHABLE
- CERTIFIED REQUEST != PRODUCTIVE REENTRY
- PRODUCTIVE REENTRY != RECERTIFICATION
- EXACT REQUEST FORWARDING != REQUEST RECONSTRUCTION
- REVISION APPROVAL != REVISION EXECUTION
- ONE APPROVAL AUTHORITY
- ONE PRODUCTIVE APPROVAL-TO-MEMORY WIRING
- ONE MEMORY AUTHORITY

## Scope boundary

G18 does **not** solve the earlier productive construction path from corrective
evidence through G13, G14, G15, and G16. Cross-turn human revision approval
continuity remains outside this gate.

## RED rule

This gate adds tests/documentation only. No production implementation belongs
in CONTRACT RED.
