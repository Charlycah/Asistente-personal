# ROBY XI.2 — INTEL-G13 — CONTRACT RED

## Gate
EXISTING DURABLE STABLE_KNOWLEDGE + GOVERNED CONTRADICTORY/CORRECTIVE EVIDENCE
→ GOVERNED KNOWLEDGE REVISION PROPOSAL

## Certified source
INTEL-G12 — SURGICAL GREEN IMPORT/SHA CORRECTIVE — CERTIFIED / CLOSED
Baseline: 14,132 PASS · Ruff clean · 0 FAIL · 0 regressions.

## Scope
This gate stops at an inert revision proposal. It does not authorize approval,
application, persistence, archive, supersession, replacement writes, actions,
automation, or a new cognitive authority.

## Contract required by GREEN
The existing durable `STABLE_KNOWLEDGE` target must be identified explicitly.
The proposal must preserve:
- target memory identity;
- target category;
- current durable content;
- proposed corrected/replacement content;
- corrective evidence identity/lineage;
- deterministic source fingerprint.

The proposal boundary must expose no Memory write and no approval/application
authority.

## Governance invariants
CONTRADICTED != WRONG
REVISION PROPOSED != APPROVED
APPROVED REVISION != APPLIED
SUPERSEDED != DELETED
RECALLED != TRUE
MEMORY != EXTERNAL EVIDENCE

## Forbidden in G13
- `OfficialMemoryGateway` duplication;
- second Memory store/runtime/reader;
- new Reasoning authority;
- direct `update_content()` or `archive()`;
- `remember_governed_learning()` / `store_governed_learning()` calls;
- human approval;
- supersession/retraction application;
- replacement persistence;
- actions or automation.

## RED tests
1. Explicit inert governed revision-proposal contract exists.
2. Proposal foundation requires an existing durable target plus corrective evidence.
3. Proposal preserves target/evidence lineage.
4. Proposal cannot approve, apply, archive, update or write.
5. Anti-duplication guard preserves existing Memory/Learning/Reasoning authorities.

Expected pre-GREEN result: four intentional seam failures and one
anti-duplication pass.
