# R-CI-SI-S5-C3 — RED CONTRACTUAL

## Governed Self-Epistemic Topic-Evidence Reachability Determination

### Purpose

Determine, without discovery or semantic inference, whether the certified C2
self-epistemic curiosity evidence has a compatible governed route to explicit
topic evidence required by the existing Relevance seam.

### Certified input

The owner accepts only an actual
`GovernedSelfEpistemicNeedCuriosityEvidenceProjection` produced by C2 and
preserves the C2/C1/B1 upstream anchors by identity.

### Contract

- R1 — require the actual C2 projection and preserve upstream anchors.
- R2 — preserve capability/source/snapshot/requirement lineage and keep
  `relevance=UNKNOWN`.
- R3 — in the currently demonstrated architecture, return only
  `NO_COMPATIBLE_GOVERNED_TOPIC_EVIDENCE_ROUTE`, with no compatible item,
  evidence reference, or inferred topics.
- R4 — never infer `InterestTopic` correspondence from capability name,
  source reference, requirement identity, subject, unknown element, evidence
  codes, tags, fuzzy/semantic matching, LLM, or retrieval.
- R5 — do not discover or fabricate topic evidence: no registry routing,
  dynamic discovery, new `GovernedInformationItem`, source selection,
  acquisition, route table, or fallback route.
- R6 — do not create `RelevanceCandidate`, invoke/assign Relevance, invoke
  Curiosity, create questions, invoke Initiative/Conversation, or ask a human.
- R7 — determination is deterministic, explicit, read-only, and derivational.
- R8 — STOP before Relevance → Curiosity → Initiative → Conversation and do
  not create parallel cognitive/downstream authorities.

### Architectural meaning

The status proves only that no compatible governed topic-evidence route is
currently demonstrated for this exact C2 lineage. It does not claim that no
future route can exist. A future positive route requires an explicit governed
contract and exact lineage; it must not appear through heuristic inference.
