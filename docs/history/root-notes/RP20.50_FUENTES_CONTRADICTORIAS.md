# RP.20.50 — Fuentes contradictorias

Roby ya no fusiona silenciosamente titulares que sostienen versiones opuestas.

Cuando dos medios distintos hablan del mismo hecho con afirmaciones incompatibles:

- expone ambas versiones por separado;
- evita presentar cualquiera como confirmada;
- reduce la confianza de `high` a `medium`;
- marca la vigencia como `recent_but_conflicting`;
- conserva las fuentes para que el usuario pueda pedirlas;
- espera una confirmación más sólida antes de resolver el conflicto.

Las noticias compatibles continúan clasificándose como web reciente de confianza alta.
