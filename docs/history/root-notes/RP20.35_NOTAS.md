# ROBY XI.2 RP.20.35

Esta revisión corrige tres degradaciones observadas en RP.20.34:

1. El archivo de actualización podía reemplazar `.roby/credentials.json` por una plantilla vacía. Este archivo ya no se distribuye dentro del ZIP.
2. Sin clave meteorológica, las consultas podían caer al modelo conversacional. Ahora quedan reservadas por la capacidad meteorológica y ROBY explica que falta OpenWeather, sin estimar valores.
3. Edge TTS recibía fragmentos demasiado largos. El pronóstico se divide en segmentos de hasta 140 caracteres y cada segmento dispone de 90 segundos.

Para una instalación nueva, copiar `.roby/credentials.example.json` como `.roby/credentials.json` y completar `OPENWEATHER_API_KEY`.
