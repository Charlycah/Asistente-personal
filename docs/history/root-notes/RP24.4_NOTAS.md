# RP.24.4 — Router Cognitivo de Modelos

Esta etapa incorpora una capa de decisión cognitiva previa a la ejecución de
proveedores. El router no llama modelos: selecciona una ruta explicable y deja
una decisión auditable.

## Criterios

- residencia local o remota;
- sensibilidad y privacidad;
- necesidad de información reciente o en vivo;
- capacidad requerida (texto, código, visión, etc.);
- complejidad de razonamiento;
- preferencia de latencia;
- preferencia de costo;
- salud y habilitación del proveedor.

## Política

Local First continúa siendo el valor predeterminado. Una consulta sensible no
puede salir de la computadora. Una consulta que exige información en vivo solo
puede usar un modelo autorizado con esa capacidad. Cuando no existe una ruta
segura, ROBY se abstiene.

Cada decisión incluye modelo seleccionado, alternativas ordenadas, puntajes,
razones y necesidad de acceso de red. Esta etapa no ejecuta proveedores ni
aprende automáticamente de las decisiones.
