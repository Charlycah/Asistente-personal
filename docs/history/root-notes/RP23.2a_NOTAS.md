# RP.23.2a — Saneamiento del asistente de configuración

## Objetivo

Cerrar la transición del asistente de configuración al modelo privado y local de ROBY, retirando de las pruebas el contrato histórico basado en `.env`.

## Cambios

- Las pruebas de `development_setup` validan `.roby/config.json`.
- Se retiraron expectativas sobre `SetupResult.env_path` y `SetupResult.backup_path`.
- Se retiraron las pruebas de `collect_setup_options`, API obsoleta ya eliminada.
- `pending_fields` se valida mediante las rutas estructuradas actuales:
  - `runtime.factory`
  - `providers.local.model`
- El siguiente paso operativo se valida como `python main.py --doctor`.
- Se confirma que el asistente no crea `.roby/credentials.json` ni solicita secretos.
- Se mantiene la separación entre configuración, credenciales e identidad personal.
- `DevelopmentConsoleConfig.env_path` fue renombrado a `config_path` para eliminar la ambigüedad histórica; la ruta ya era `.roby/config.json`.

## Contrato vigente

- Configuración: `.roby/config.json`
- Credenciales privadas: `.roby/credentials.json`
- Perfil personal: `.roby/profile.local.toml`
- No se usa `.env`.
- No se usa `python-dotenv`.
- No existe compatibilidad ejecutable con el contrato retirado.

## Validación en el entorno de construcción

- `pytest -q`: 6779 pruebas aprobadas.
- `python -m compileall`: aprobado.
- Búsqueda en módulos Python de `.env`, `dotenv`, `env_path`, `backup_path` y `collect_setup_options`: sin coincidencias activas.
- `ruff` no estaba instalado en el entorno de construcción; debe confirmarse localmente con `ruff check .`.
