# RP.20.54 — Registro interno de confianza

Esta revisión convierte la metadata de origen introducida en RP.20.49 en un registro
auditable de decisión para todas las respuestas.

Cada respuesta conserva:

- origen de la información;
- nivel de confianza;
- vigencia;
- cantidad de evidencias aceptadas;
- presencia de fuentes contradictorias;
- estado de verificación;
- decisión de responder o abstenerse;
- código concreto del motivo.

El registro se valida antes de emitir la respuesta. Por construcción, Roby rechaza
combinaciones incoherentes, por ejemplo:

- una respuesta verificada sin evidencia;
- una abstención con confianza distinta de `withheld`;
- fuentes contradictorias con confianza alta;
- una decisión respondida marcada simultáneamente como abstención.

En actualidad, el número de fuentes aceptadas se registra después de aplicar la
política de edad máxima. Las contradicciones usan verificación parcial y confianza
media. Las abstenciones conservan el motivo exacto, como fallo de recuperación o
falta de fuentes suficientemente recientes.

El registro completo forma parte de la identidad SHA-256 del resultado del pipeline.
