# RP.20.53 — Conservar el contexto de actualidad

Esta revisión agrega memoria conversacional específica al Router de Actualidad.

## Contexto conservado por sesión

Roby recuerda, únicamente dentro de la sesión activa:

- la consulta web resuelta;
- el tema principal;
- la ventana temporal aplicada;
- las fuentes recientes aceptadas;
- el último motivo de abstención.

## Seguimientos contextuales

Después de una consulta como:

```text
Últimas noticias de la NASA
```

Roby puede interpretar:

```text
¿Y SpaceX?
```

como una nueva consulta reciente sobre SpaceX.

También reutiliza el tema cuando el seguimiento cambia solamente el período:

```text
¿Y esta semana?
```

Si Roby se abstuvo, una pregunta como:

```text
¿Por qué no respondiste?
```

recupera la explicación concreta de esa abstención.

## Límites de seguridad

- El contexto se mantiene aislado por `session_id`.
- No se comparte información entre sesiones.
- Los seguimientos solo se resuelven cuando existe un contexto previo de actualidad.
- Las preguntas comunes que no encajan en esos patrones continúan hacia la conversación general.
- Las fuentes recordadas siguen siendo únicamente las que superaron las reglas de vigencia.
