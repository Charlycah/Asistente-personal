# RP.20.46 — Desambiguación de pronósticos

La palabra «pronóstico» ya no activa por sí sola el servicio meteorológico.
Roby exige contexto de clima o de horizonte temporal meteorológico, como
«pronóstico extendido», «pronóstico para mañana», «lluvia» o «temperatura».

Consultas predictivas generales o deportivas, por ejemplo «¿quién gana entre
Argentina y España?», continúan hacia el flujo conversacional general.
