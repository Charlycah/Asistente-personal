# RP.20.52 — Explicar por qué no responde

Roby ya no se limita a decir que no puede responder una consulta de actualidad.
Cada abstención expone cuatro elementos:

1. que no puede responder con confianza;
2. el motivo concreto del fallo;
3. el criterio de seguridad que no se cumplió;
4. una forma responsable de continuar.

La explicación distingue entre búsqueda web desactivada, error de recuperación,
ausencia total de fuentes y fuentes rechazadas por antigüedad, fecha desconocida
o fecha futura inconsistente.

El código de la causa queda también registrado en `rationale`, por ejemplo:

- `current_affairs_abstained:web_search_disabled`
- `current_affairs_abstained:web_retrieval_failed`
- `current_affairs_abstained:no_sources_found`
- `current_affairs_abstained:freshness_requirements_not_met`

Roby mantiene la abstención y nunca deriva silenciosamente la consulta al modelo.
