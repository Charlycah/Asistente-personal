# M304.3 — Respuesta meteorológica natural

- Los comentarios como «el día está muy feo» se enrutan al clima real.
- «nubes» se expresa como «nublado».
- Lluvia, llovizna, niebla y neblina usan frases naturales.
- La sensación térmica se informa siempre, incluso cuando coincide con la temperatura.
- Se conserva la versión corregida de `app/desktop_ui.py` entregada por el usuario.
