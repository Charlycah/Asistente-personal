# M148 — Living Conversation Presence Awareness

M148 converts governed M147 Living Conversation presence cues into an immutable awareness state for the conversational domain.

## Responsibility
- select the newest valid M147 consumer result;
- validate owner, freshness, confidence, and result limits;
- preserve exact M147 result and cue lineage;
- classify awareness as stable, transitional, uncertain, or interrupted;
- expose availability, completeness, confidence, and normalized awareness flags;
- represent complete, partial, empty, review, blocked, and not-applicable outcomes.

## Explicit exclusions
M148 does not decide whether to converse, activate Living Conversation, select timing, generate prompts, realize responses, infer identity/activity/intent, adapt behavior, call providers, automate actions, or mutate the platform.
