# RP.17 — Cognitive Episodic Memory

RP.17 incorpora una memoria episódica ejecutiva, breve y gobernada al ciclo
cognitivo residente de ROBY.

## Propósito

Registrar cambios significativos del modelo cognitivo del mundo para conservar
una historia auditable de cómo evolucionó el foco, sin almacenar razonamiento
privado ni convertir inferencias en hechos.

## Flujo

Agenda → Reasoning → Reflection → Thought Stream → Hypothesis Workspace →
World Model → Episodic Memory → Continuous Cognitive State

## Episodios

Cada episodio conserva únicamente metadatos ejecutivos:

- transición del modelo del mundo;
- foco e hipótesis líder;
- entidades y relaciones involucradas;
- confianza agregada;
- fuentes;
- resumen y rationale auditables;
- cantidad de repeticiones equivalentes.

## Gobernanza

La memoria episódica:

- no ejecuta capacidades;
- no modifica agenda, hipótesis ni modelo del mundo;
- no requiere autorización del usuario;
- no guarda cadena de pensamiento ni pasos privados de razonamiento;
- mantiene límites configurables y consolida repeticiones equivalentes.
