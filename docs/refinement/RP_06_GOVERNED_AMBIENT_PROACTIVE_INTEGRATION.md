# ROBY XI.2 — RP.06 Governed Ambient Proactive Integration

RP.06 connects resident ambient awareness, conversational self-analysis,
controlled initiative, and governed visual capture.

## Operational model

1. An external local sensor boundary may remain resident and classify ambient
   events under standing user consent.
2. ROBY receives compact event summaries, not unrestricted raw household audio.
3. Private household speech is restrained by default and does not trigger
   proactive commentary.
4. Strong impact or distress signals may justify a brief check-in.
5. ROBY may request a camera capture when visual confirmation is materially
   useful, standing camera consent exists, and cooldown rules allow it.
6. Camera activation remains behind the existing tool gateway and permission
   boundary.
7. Conversational self-analysis can suppress nonurgent initiative when ROBY
   should first repair context or interaction quality.

RP.06 does not add public commands, unrestricted surveillance, automatic
recording, face recognition, code modification, or external actions.
