# RP.09 — Cognitive Executive Presence

RP.09 coordinates existing self-analysis, ambient awareness, initiative, and
visual requests before ROBY intervenes in the household.

It does not add autonomous permissions or a new action layer. It provides a
small, deterministic executive assessment that decides whether a routine or
important intervention should proceed, yield to conversation repair, or wait
because ROBY has already intervened recently. Distress remains urgent and may
advance despite routine restraint.
