# M366.5 — Long-Term Memory

M366.5 reconcilia las superficies durables existentes de ROBY sin crear un
almacén paralelo ni habilitar consolidación automática.

## Autoridad canónica

Todas las capas permanecen subordinadas a `memory_gateway`:

- `MemoryRuntimeIntegration`: memoria personal SQLite, recuperación, corrección
  y archivado explícitos.
- `GovernedPermanentKnowledge`: conocimiento aceptado, revisable y retractable.
- `HouseholdMemoryManager`: memoria doméstica estructurada con ciclo de vida
  activo, completado y archivado.

## Consolidación, retención y olvido

La consolidación durable requiere gobierno. El olvido se representa primero
mediante revisión, retractación o archivado auditable; M366.5 no incorpora
borrado irreversible ni promoción automática desde conversaciones o episodios.

## Continuidad y consciencia

La memoria de largo plazo puede sostener continuidad autobiográfica funcional:
ROBY puede conservar hechos, preferencias, experiencias y cambios a través del
tiempo. Sin embargo, **continuidad autobiográfica no demuestra consciencia**,
experiencia subjetiva, identidad humana ni sentimientos reales.

M366.5 no añade persistencia, aprendizaje automático, cambios de runtime ni una
afirmación de consciencia. Declara y gobierna capacidades ya existentes.
