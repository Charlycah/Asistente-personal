# CERTIFICATION RP.18.5

## Single Capability Route

Se certifica que toda ejecución de capacidades registradas atraviesa una única
frontera oficial:

- registro canónico único;
- gateway de ejecución único;
- trazabilidad del origen de cada invocación;
- planners, directores, coordinadores y orquestadores sin acceso directo a
  interceptores registrados;
- ausencia de un segundo lifecycle o registro paralelo.
