# CERTIFICATION RP.18.6

## Unified Runtime Observability

Se certifica una única superficie oficial de observabilidad:

- lectura de estados canónicos sin duplicación;
- integración de lifecycle, residentes, salud y readiness;
- integración de gateways conversacional y de capacidades;
- visibilidad del núcleo cognitivo oficial;
- recuperación opcional basada en el grafo oficial;
- serialización estable para diagnóstico.
