## 2. Existing authority inventory

### Memory and contextual retrieval

Canonical memory authority already exists. `CognitiveMemoryRecall` collects,
filters and ranks governed memory candidates. M36/M37 explicitly remain without
embeddings, external neural retrieval or autonomous memory writes.

`ContextualMemoryRetrievalFoundation` is read-only, excludes archived and
superseded memories, requires review for conflicts and names
`CognitiveMemoryRecall` as specialized retrieval.

Classification: `EXISTING AUTHORITY / PARTIAL NEURAL ASSISTANCE`.

### Conversational intent and state

`AppliedConversationalIntelligence` and the existing cognitive/conversation
pipeline already own governed conversational interpretation and routing.

Classification: `EXISTING / DUPLICATE-RISK`.

A neural classifier could only be advisory evidence under an existing owner.
No second intent authority is justified by this inventory.

### Affective / prosodic assistance

`GovernedAffectiveEvaluator`, relational-affective evidence, simulated inner
state and governed expressive modulation already define bounded affective and
expression semantics. The evaluator is explicitly not an authority.
Expression cannot change facts, permissions or decisions.

Classification: `EXISTING + PARTIAL / HIGH DUPLICATE-RISK`.

A future neural cue detector could supply bounded evidence only; it cannot
claim subjective emotion or directly mutate personality/inner state.

### STT and TTS

Local/offline STT already exists through the `SpeechRecognitionBackend`
contract and Vosk implementation. TTS already exists through Edge TTS with
configured neural voices and governed voice/prosody formatting.

Classification: `EXISTING / PROVIDER-SPECIALIZATION ONLY`.

Replacing providers is not a new cognitive authority. Voice Identity remains a
separate future quality horizon and is not selected here.

### Vision and multimodal inference

`OfficialVisionCore` and `IntelligentVisionService` already own governed visual
capture/inference with explicit permission, consent and requested capability
boundaries.

Classification: `EXISTING / PROVIDER-SPECIALIZATION ONLY`.

A neural visual model must remain behind these authorities rather than create a
parallel vision brain.

### Learning and persistence

Governed learning, explicit human approval and official memory-write authority
already exist. Neural inference has no direct write authority.

Classification: `EXISTING / CLOSED AUTHORITY BOUNDARY`.

`DIRECT_NEURAL_MEMORY_OR_LEARNING_WRITE: FORBIDDEN`.

## 3. Use-case classification

- Embedding/vector memory retrieval: `PARTIAL / DEFER`. It requires indexing,
  persistence and privacy design; it is too broad as the first seam.
- Contextual memory neural reranking: `MISSING BOUNDED ASSISTANCE`. A strong
  reusable owner/consumer path exists and no write authority is required.
- Intent classification: `EXISTING / DUPLICATE-RISK`. Existing interpretation
  authorities must remain canonical.
- Conversational-state classification: `PARTIAL / DUPLICATE-RISK`. It may
  become evidence only after an exact gap is proven.
- Affective/prosodic cue detection: `PARTIAL / DUPLICATE-RISK`. Existing
  affective and expressive authorities already bound semantics.
- Speaker recognition: `MISSING / FUTURE`. Identity, privacy and consent
  implications make it unsuitable as the first seam.
- Vision specialist inference: `EXISTING / PROVIDER-SPECIALIZATION`. It must
  stay behind `OfficialVisionCore`.
- STT specialization: `EXISTING / PROVIDER-SPECIALIZATION`. The backend
  contract and Vosk path already exist.
- TTS specialization: `EXISTING / PROVIDER-SPECIALIZATION`. The Edge TTS
  neural voice path already exists.
- Style adaptation: `EXISTING / DUPLICATE-RISK`. Stable/adaptive personality
  and expressive modulation already own it.
- Small local specialist models: `ABSTRACT / NOT SELECTABLE`. One exact
  governed use case must justify them first.

## 4. First bounded candidate demonstrated by the inventory

The smallest high-value seam is not embedding persistence or a vector database.
It is advisory semantic reranking of an already-governed memory candidate set.

Existing path:

`Memory authority -> CognitiveMemoryRecall candidate collection -> profile/status
filtering -> deterministic scoring/ranking -> governed consumer`

Candidate future seam:

`filtered governed candidates -> bounded neural relevance evidence -> existing
memory retrieval authority -> final governed selection`

The neural component would not:

- collect arbitrary new memories;
- write or modify memory;
- bypass profile, archived, superseded or conflict rules;
- inject directly into prompts;
- decide Learning admission;
- become a Memory authority;
- require embedding persistence as a precondition;
- remove the deterministic existing ranking fallback.

## 5. Required PRE-RED questions

Before any contract is written, the next reconciliation must prove:

1. the exact canonical insertion seam between governed candidate filtering and
   final relevance ordering;
2. whether `CognitiveMemoryRecall` or the contextual retrieval foundation is
   the canonical consumer boundary;
3. the minimal advisory output representation;
4. confidence and abstention semantics;
5. deterministic fallback to current scoring when the specialist is absent,
   unavailable or abstains;
6. provenance/observability without exposing private memory content;
7. no persistence, vector store or background indexing;
8. no change to Memory/Learning admission or write authority;
9. measurable user-facing value over the current lexical/contextual ranking;
10. historical contracts that intentionally prohibit embeddings or semantic
    matching and whether they apply to this bounded reranking seam.
