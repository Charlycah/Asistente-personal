# ROBY M264 — End-to-End Conversation Runtime

M264 closes the Total Integration Master Plan by connecting the certified M257-M263
runtimes through one observable, governed conversation coordinator.

The runtime reuses the exact official instances from the composition root. It classifies
entry, applies bounded session context, evaluates conversation intelligence, and routes
questions through governed reasoning and adaptive cognition. Device, driving, and
external retrieval remain explicit governed capabilities and are never invoked implicitly.

The runtime does not itself call providers, access networks, mutate platforms, control
devices, or authorize actions.
